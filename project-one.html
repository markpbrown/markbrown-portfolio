    AI Chatbot Platform

    Project Overview

    This is a custom AI chatbot application built on Node.js, designed to help small businesses deploy an automated chat agent capable of handling customer service interactions directly.

    The application integrates a basic web scraping component that programmatically extracts text data from a business's public web pages or documents to automatically compile its initial knowledge base. The core logic engine then utilizes a Retrieval-Augmented Generation (RAG) framework; when a user asks a question, the system dynamically searches this scraped data to retrieve relevant background context before passing it to the language model. By combining this workflow with efficient asynchronous API handling and clean conversational state management, the chatbot provides highly specific, context-aware answers within defined customer service boundaries while keeping backend resource overhead minimal.
