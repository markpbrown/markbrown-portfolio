    AI-Enhanced VR Job Interview Simulator

    *Note: This was a University Capstone Group Project

    Project Overview

    This is a VR job interview simulator built in Unity for the Meta Quest 3, designed to help users bridge the gap between technical knowledge and real-world communication confidence.

    Users can select different job categories and difficulty levels, and the AI interviewer fluidly adapts its line of questioning based on those choices to keep the experience realistic and varied. It focuses VR interaction mechanics and analyses performance metrics—like vocal delivery and response context—to give users immediate, practical feedback during the session.

    The project also features a dedicated analytics dashboard to track progress. It includes secure role management, providing admins a birds-eye view of all user interview metrics while restricting standard users to their own historical stats.

    Tech Stack & Tools

    Built with scalability and fluid integration patterns:

    C# Unity VR Firebase Google Gemini API Google Cloud Speech-to-Text API
